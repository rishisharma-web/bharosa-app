AI where the world is messy. Code where money moves.

AI does
Understands the shopkeeper's Hindi, Kannada or Hinglish (Counter Agent)
Writes reminders and reads customers' replies (Recovery Agent)
Guesses who sent an unclear payment (Reconciliation Agent)
Plans with tools and explains options (Munim Agent)
Code does
Safe limits and bands (risk formula)
Balances, FIFO allocation, the ledger state machine
Auto-pay debits, advance sizing and the 20% split
Scores and fraud rules
  1. One source of truth: the backend ledger.
  2. Everything is an event, persisted and replayable.
  3. The LLM proposes, code decides, through validators.
  4. Adapters at every boundary: swap them and this runs on Paytm.
  5. Every step traced; merchants never see other stores' data.
